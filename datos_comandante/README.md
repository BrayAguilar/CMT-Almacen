# Paquetes depurados para Comandante

Sube aquí únicamente los JSON creados desde el botón **Crear archivo para Comandante** de Administración. Estos paquetes incluyen existencias y cifras agrupadas por nombre de unidad, sin folios, nombres personales, números de documento ni observaciones. Los nombres de las unidades, modelos, fechas y cantidades quedan públicos en este repositorio.
