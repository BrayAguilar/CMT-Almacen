# Paquetes depurados para Comandante

Sube aquí únicamente los JSON creados desde el botón **Crear paquete depurado para Comandante** de Administración. Estos paquetes incluyen existencias y cifras agrupadas con claves anónimas de unidad, sin folios, nombres personales, números de documento ni observaciones. Los datos que sí se incluyen —modelos, fechas y cantidades— quedan públicos en este repositorio.
